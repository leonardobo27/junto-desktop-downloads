# Juntô para Windows e Mac

Instaladores e metadados de atualização da versão de avaliação. O código do aplicativo permanece no repositório privado.

Downloads e instruções: https://jogajunto-app.pages.dev/download/

Windows 11 x64; macOS 13+ universal para Intel e Apple Silicon. A interface é instalada no computador e usa as mesmas contas e dados online.

Windows verifica atualizações com confirmação de download e instalação. Mac recebe atualizações pelo instalador até haver certificado Apple Developer e notarização. Os pacotes de avaliação podem mostrar avisos de distribuição; Mac usa assinatura ad hoc. Não houve teste em Mac físico.

O manifesto registra commit de origem, checksums, compilações e alcance dos testes. Login por e-mail real, reinício de sessão e atualização NSIS real foram verificados. O retorno Google foi verificado com backend simulado; login Google real e ciclo integral de operações autenticadas ainda exigem avaliação.
